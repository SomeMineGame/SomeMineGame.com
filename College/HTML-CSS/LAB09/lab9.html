Ridgewater CST Club Minecraft Server

I am hosting the servers for Minecraft and other games for the CST club at Ridgewater! I've made a Discord bot as well as an in-progress Python bot for the Discord server. The server features a stats page and live map. The bot's code is publicly accessible on GitHub. Currently, it lists the current day of the server and allows members to add themselves to the whitelist and automatically update's their usernames in Discord to match their Minecraft usernames!
